# Bóveda EDH

Tus mazos de Commander, Pauper y Pioneer, tu colección de ManaBox, carpetas de venta, matchups de Pauper y alertas de precios.

La página completa está en `index.html` (un solo archivo, sin compilación). Netlify la publica tal cual: sin comando de build y con `/` como carpeta de publicación.

Tus datos (mazos, colección, respaldos) se guardan solo en tu navegador; este repositorio contiene únicamente el código de la página.
